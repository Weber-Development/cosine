# @sweberdev/cosine-react

React bindings for [Cosine](https://packages.sweber.dev/cosine): `<CosineSearch>`, `useCosine` and `useCosineSearch`.

```tsx
import { CosineSearch } from "@sweberdev/cosine-react";

<CosineSearch index="/cosine/cosine-index.json" lang="de" shortcut="mod+k" />;
```

Docs: [packages.sweber.dev/cosine/docs/guides/react](https://packages.sweber.dev/cosine/docs/guides/react). MIT licence.
